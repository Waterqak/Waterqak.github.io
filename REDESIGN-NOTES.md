# made by Water | site notes

This project is a minimalist portfolio for Water, a solo Roblox game developer. It uses a quiet dark palette, restrained blue accent, simple section navigation, and short page transitions.

## Current behavior

- Home has a concise introduction with room for a future avatar.
- About explains the developer's scope and practical systems work.
- All projects uses a stable table header. The project rows and detail panel scroll independently, and selecting a project returns its detail panel to the top.
- Selected Work highlights Chillin Place, Weather System, Dialogue System, and Project Halo, in that order.
- Code, Experience, and Contact remain available from the main navigation.
- The old circular wheel and hero terminal remain removed.
- Buttons use restrained color and border transitions without the older expanding fill effect.
- No em dash characters are used in the editable website copy.

## Local testing

Open `index.html` using the project's normal local setup. Check the All projects page after navigating away and back, test project selection and filtering, and verify the layout at desktop and mobile sizes. Respect the system's reduced-motion preference when checking transitions.

## Avatar asset

Place a transparent full-body avatar render at `assets/images/water-avatar.png`. The shared avatar layer is optional and remains hidden until the image loads.
